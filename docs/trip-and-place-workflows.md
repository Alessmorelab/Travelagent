# 行程信息与地点收藏

## 完善已保存的行程

在「行程」页点击「编辑日期、人数与预算」，可修改行程名称、目的地、出发日期、同行人数、计划总预算和出行备注。日期、人数和预算尚不确定时可以留空。

出发日期确定后，返程日期按现有每日安排自动计算，支持跨月、跨年和闰年。修改基本信息不重建每日安排，也不改变用户的全局旅行偏好；保留原始回复、查询依据和完成进度。更换目的地时会清除原地点绑定，避免新城市复用旧坐标。

旧版本导入的 AI 行程可以补填这些信息，重新打开小程序后仍能恢复。原始回复及其中的天气、预约和开放信息不会因调整日期自动更新，需要按新出行日期重新确认。

## 收藏实际地点

在「行程 → 地点地图」的查询结果中，或者在按天行程地图中确认一个地点后，可点击「收藏地点」。只接受具有真实查询来源、有效 GCJ-02 坐标和查询时间的地点数据。

「收藏」页提供两种内容：

- 「地点收藏」保存实际地点，可按名称、地址或城市筛选，打开位置、移除收藏，或加入已有行程的指定一天。
- 「灵感目的地」保留原有的目的地介绍和示例预算，继续作为旅行灵感使用。

加入每日行程时保留地点的地址、坐标与来源，游览时间标为待定。同一地点不会重复加入同一天；不同日期可以重复安排。取消地点收藏不会删除已加入行程的安排。示例行程不作为加入目标，需先创建或保存自己的行程。

地点收藏保存在当前设备，最多200个；不要求登录、不调用模型，也不表示票价、开放时间或实时可用性已更新。

## 复制与分享

「行程 → 复制行程」会将当前编辑后的名称、日期、人数、计划预算、每日安排和备注复制到剪贴板，由用户自行粘贴分享。复制内容区分示例与草稿，原回复附注会标明日期及实时信息需重新确认。

## 用 AI 调整一天的安排

1. 打开自己保存的行程并选择日期。点击已预约的活动，可在编辑面板中锁定；锁定会保存到本机。移动、编辑或删除其他活动不会清空当天的完成记录。
2. 点击「AI 调整当天」，勾选要替换的活动。例如只勾选下午的公园，填写「把户外活动改成室内，保留原时间」。已锁定、已完成和未选中的安排都会保留。
3. 核对原安排和新建议。地点变更时可以查询并选择实际地点；若新旧路线的两端都已确认，可选择一段相邻路段，比较调整前后的步行耗时。原地点可先在「行程地图」确认。没有可比数据时不显示估算。
4. 确认保存才修改这一天。小程序当前运行期间，可撤销最近一次调整；同一天有后续改动时，旧预览和撤销操作不会覆盖新内容。

首版支持包含最多12项安排的一天，一次替换最多4项，保持原有数量与顺序。模型接收当天的活动、日期、目的地和调整要求，生成建议时不写入行程或聊天记录。建议不会验证营业时间、天气或可预约情况；交通耗时来自独立地图查询。新地点未经确认时不继承旧坐标。

## 验证范围

回归测试覆盖基本信息的补填与恢复、跨年和闰年日期、目的地变化后清除旧坐标、收藏去重与恢复、加入指定天、移除收藏后保留行程，以及分享文本使用当前编辑内容。TypeScript、微信端编译和模拟页面挂载另作检查。

原生日期选择器、打开位置和剪贴板的设备表现仍需微信真机验收。
